# ReadIt

ReadIt 是一个 Android 平台的英文阅读器

[![Release](https://img.shields.io/github/v/release/oracole/ReadIt?color=D9534F)](https://github.com/oracole/ReadIt/releases/latest)
[![dict.db](https://img.shields.io/badge/下载词典数据-dict.db-blue)](https://github.com/oracole/ReadIt/releases/download/dict/dict.db)

---

## 目的

阅读英语文章遇到生词时，传统词典往往会给出多个释义，读者需要耗费精力从中挑出最符合当前语境的释义来理解，有时词典中甚至并没有收录最贴切的引申义

因此，ReadIt 有两个主要的功能：

### 词典查询

基于导入词典数据，离线返回这个词在词典中的释义

### AI 查询

这是这个应用主要的功能，具体说明见 功能 - 点词查询

阅读时，直接点击单词，在词汇卡片中展开“语境义”项目，应用会给出这个词在这一句话中最贴合语境的含义

另外可按需选择，展开词根、搭配、例句、音标四个项目的详细信息


### 示例

“看得懂词汇，却无法理解它在上下文中的意义”在阅读中是很常见的情况，尤其当词汇偏学术或由口语中含义引申而来时。具体来说，这是一个例子：

> English does not have one style. A related issue is register. 

> 英语并非只有一种风格，一个相关的问题是语域。

对于 register（n. 语域），例句中使用了较为学术的用法，应用中的词典和 AI 分别给出了释义：

### **词典的释义**

`n. 寄存器，记录，登记簿，注册
vt. 记录，注册，提示，表达，把...挂号
vi. 登记，注册，挂号
[计] 寄存器` 

### **语境释义（AI）**

`语域；语言使用域` 

### **语感（AI）**

`语言学用语，指随场合变化的语言变体。`

## 功能

**导入文章**

支持选择 TXT 文件或者直接粘贴文本，导入时自动识别 UTF-8 与 GBK 编码

**点词查询**

点击正文里任意一个单词就会弹出词汇卡片，卡片顶部是词典给出的释义，下面有五个可以展开的项目

| 项目 | 说明 |
|---|---|
| 语境义 | 这个词在当前句子里的含义 |
| 词根 | 构词分析与词源 |
| 搭配 | 常见搭配及其含义 |
| 例句 | 例句及中文翻译 |
| 音标 | 英式音标与美式音标 |

这些项都是按需展开，没有展开就不会发出请求

**句子操作**

阅读页面中，长按正文进入选择模式，可以选中包含这个词的整句、朗读选中的内容、翻译选中的句子、把多个选中词当作一个词组来查询，或复制选中的内容

**生词收藏**

在释义卡片里点击书签图标即可收藏，收藏时会记录单词、音标、释义、出处句子和所属文章，同一个单词可以记录多个出处，触发方式：点击语境义卡片

**词汇表导入**

支持 CSV、TSV、Anki 导出的 txt，也可以直接粘贴文本，导入过程分四步，选择文件、预览、导入、结果，对于词典中未收录的词汇，释义来源有三种可选：

| 释义来源 | 说明 |
|---|---|
| 由 AI 生成 | 由 AI 生成释义 |
| 采用文件内 | 使用文件内自带的释义，需保证排版准确 |
| 不保留 | 只导入词典收录的词，其余的跳过 |

**用生词生成文章**

把选中的生词交给 AI，让它写一篇包含这些词的新文章，可以配置 CEFR 六档难度、篇幅、融合度、主题和额外要求

**全文翻译**

在阅读页右上角的菜单里进入，输出形式有三种，纯中文、句对照、段对照，翻译时按段落分批请求，每批八段

**朗读**

朗读使用系统自带的 TTS 引擎，语速可以在 50% 到 200% 之间调整

强烈建议安装 Google 的 Speech Recognition & Synthesis，这是谷歌的 TTS 引擎，可以很大改善 TTS 质量。如果不配置，会使用系统内置的 TTS，比如小米手机就是小爱的声音，很塑料，但是作为基本的词重音示范可能有一定参考价值


### 不建议使用这个软件阅读长篇书籍，性能比较抽象😭

## 使用之前要准备的

**词典文件**

词典太大了，所以不随应用打包，需要单独导入，在设置页里选择一个 ECDICT 的 SQLite 数据库文件即可

词典文件可以从本项目的 Releases 下载，文件名是 `dict.db`，大约 200 MB

下载之后在应用的设置页里选择这个文件导入，导入过程通常不超过 10 秒钟，取决于手机的存储速度

本项目 `dict.db` 数据来源： <https://github.com/skywind3000/ECDICT>，采用 MIT 协议

**API 密钥**

AI 相关的功能都需要用到密钥，需要先在 DeepSeek 平台申请一个然后填写在设置页里，默认只连接 DeepSeek，也建议用 DeepSeek（因为大肥鱼很便宜，用很久可能不到一块钱）

接入其他 OpenAI 兼容服务，请参照服务提供方技术文档在设置页配置 API 接口

## 安装

正式版的安装包在 Releases 页面

第一次打开需要先导入词典，然后到设置里配置 API，配置完即可

---

## 构建

构建要求 JDK 17 和 Android SDK 34

```bash
./gradlew assembleRelease
```

SDK 路径在 `local.properties` 里通过 `sdk.dir` 指定

---

## 代码结构

```
app/src/main/java/com/oracole/readit/
  data/          仓库层，包括文章、词典、生词和设置
  data/ai/       DeepSeek 请求、提示词、缓存和用量统计
  ui/screen/     各个页面
  ui/reader/     阅读页，包括分段、分词和释义卡片
  ui/theme/      配色、动效和字体
  ui/component/  可复用的组件
```
